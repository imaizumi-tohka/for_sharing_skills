# create-study-material

OCR済みPDFから学習コンテンツ（キーワード解説・要約・理解確認問題）を自動生成するスキル。

## 使用方法

```
/create-study-material <PDFパス>
```

## 入力

- **$ARGUMENTS**: OCR済みPDFファイルのパス

## 実行手順

### Step 1: PDFからテキスト抽出

ヘルパースクリプトを使用してPDFからテキストを抽出:

```bash
python ~/Projects/OCR/extract_pdf_text.py "$ARGUMENTS" --pretty
```

このスクリプトは以下を自動で行う:
- 目次ページの探索（最初の15ページをスキャン）
- 章構成の検出（目次から章タイトルとページ番号を抽出）
- 各章のテキスト抽出
- 目次が見つからない場合は本全体を1章として処理

出力はJSON形式:
```json
{
  "title": "書籍タイトル",
  "total_pages": 300,
  "has_toc": true,
  "chapters": [
    {
      "number": 1,
      "title": "第1章のタイトル",
      "start_page": 10,
      "end_page": 45,
      "text": "章のテキスト..."
    }
  ]
}
```

### Step 2: 出力ファイル確認

出力先: `{PDFファイル名}_study.md`（PDF同階層）

既存ファイルがある場合はユーザーに上書き確認を求める。

### Step 3: 各章の学習コンテンツ生成

各章について以下を生成（Claudeが直接処理）:

#### 3.1 メタ情報
- 学習目標（2〜4項目）
- 前提知識
- 学習時間目安（内容の複雑さから算出）

#### 3.2 キーワード解説
- 章の長さに応じて5〜15個程度
- 各キーワードに詳細な解説
- コードサンプルがあれば含める

#### 3.3 内容要約
- 理解確認問題に回答できる粒度で要約
- 章の本質を凝縮

#### 3.4 理解確認問題（5〜15問）
- **記述式**: 概念の説明を求める問題
- **○×問題**: 正誤判定
- **穴埋め問題**: フレーズ単位の空欄補充
- 難易度は混合（基礎・応用・発展）
- 各問題の直後に正解と解説を配置

### Step 4: 総合問題生成

全章を通した理解確認問題（10問程度）:
- 章横断的な内容
- 実践的な応用問題
- **注意**: 総合問題は各章の「内容要約」セクションから作成する（全テキストを再読み込みしない）

### Step 5: コンテキスト管理

大きな本（数百ページ以上）の場合：
- 章ごとに処理し、完了したらファイルに書き込む
- コンテキストが溢れそうな場合、処理済みの章の詳細テキストはクリアしてよい
- 最後の総合問題は、各章の「内容要約」セクションを読み込んで作成する
- これにより、コンテキストを効率的に使いながら全章を処理できる

### Step 6: 品質チェック

AIセルフチェック:
- 問題と解答の整合性確認
- 難易度バランスの確認
- キーワードと要約の網羅性確認

### Step 7: Markdown出力

出力ファイル: `{PDFファイル名}_study.md`（PDF同階層）

既存ファイルがある場合は上書き確認を求める。

## 出力フォーマット

```markdown
# 「{書籍タイトル}」学習コンテンツ

---

## 第1章: {章タイトル}

### 学習目標
- 目標1
- 目標2

### 前提知識
- 必要な知識

### 学習時間目安
約XX分

### キーワード解説

#### 1. {キーワード1}
解説文...

#### 2. {キーワード2}
解説文...

### 内容要約
要約文...

### 理解確認問題

#### 問1（基礎・記述式）
問題文

**解答**: 解答
**解説**: 解説

#### 問2（応用・○×問題）
命題文。○か×か。

**解答**: ○/×
**解説**: 解説

#### 問3（発展・穴埋め問題）
「＿＿＿」に当てはまる語句を答えよ。

**解答**: 答え
**解説**: 解説

---

## 第2章: {章タイトル}
...

---

## 総合問題

### 問1（章横断・実践問題）
問題文

**解答**: 解答
**解説**: 解説

...
```

## 進捗表示

処理中は以下のように進捗を表示:

- 「PDFを読み込み中...」
- 「目次を解析中...」
- 「第N章: テキスト抽出中...」
- 「第N章: キーワード抽出中...」
- 「第N章: 要約生成中...」
- 「第N章: 問題生成中...」
- 「総合問題を生成中...」
- 「品質チェック中...」
- 「ファイルを出力中...」

## エラーハンドリング

- **PDFが開けない**: エラーメッセージを表示して終了
- **OCRテキストが空**: ユーザーに手動入力を求める
- **目次が見つからない**: 本全体を1章として処理
- **出力ファイルが既存**: 上書き確認を求める

## 実行例

```
/create-study-material ~/電子図書/IT/Python入門.pdf
```

→ `~/電子図書/IT/Python入門_study.md` を生成
